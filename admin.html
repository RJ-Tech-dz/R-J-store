ربط لوحة التحكم بمستودع GitHub

لكي يحفظ زر "حفظ ونشر" تعديلاتك مباشرة على الموقع الحي، تحتاج لإنشاء Personal Access Token من نوع Fine-grained من حسابك في GitHub، بصلاحية Contents: Read and write على مستودع الموقع فقط. الرمز يُحفظ في متصفحك فقط ولا يُرسل لأي جهة غير GitHub.

ملاحظة حول حجم الصور

كل صورة تُرفع تُضغط وتُصغَّر تلقائيًا داخل متصفحك قبل الحفظ للحفاظ على سرعة الموقع. مع ذلك، كل صورة تضيف تقريبًا 60-150 كيلوبايت لملف data.json. إن وصل عدد المنتجات المصوّرة لعدة عشرات، قد يصبح التحميل عبر GitHub API أبطأ قليلاً — الأداء على الموقع نفسه يبقى سريعًا لأن الصور مضغوطة أصلاً.
